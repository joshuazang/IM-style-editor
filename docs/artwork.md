# Occult field journal

Choose **More options → Appearance → Artwork → Occult field journal**, with Background artwork enabled. The artwork choice is saved in the current note's existing settings. Classic and Engraved garden remain available; the default and other notes' choices are unchanged.

The composition combines UFO sightings, lost observatories, overgrown ruins, expedition equipment, natural-history specimens, enchanted forests, nocturnal scholarship and maritime cosmic horror. Local revisions replace the footprint with a crescent compass, repair the nautilus specimen bottle, replace the skull inkwell with a Cthulhu statuette, and replace the bottom-left specimen jar with a barnacled sea bell.

The illustration was generated and refined using image generation, then converted to monochrome vector contours using ImageTracerJS 1.2.6 (public domain; source blob `97f6558a304ff574e176067e1ca2edfd6c06186a`). The tracing utility is a creation tool, not an editor dependency. The shipped SVG contains 1,864 contour paths shared across four reflected placements to continue through repeat boundaries. Its negative space is transparent, with a uniform soft ink tint; it adds no screen-edge gradient or opaque paper background.

`next/assets/occult-field-journal-v1.svg` contains no embedded bitmap, script, font, external reference or animation. The editor loads it from its own asset directory only when this artwork is selected. It adds no note processing, timer, browser storage or independent network service. Archive's artwork and runtime are unchanged.
