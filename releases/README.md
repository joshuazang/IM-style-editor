# Release history

Current install manifests and distribution packages stay at the repository root.
Older files are grouped below; no historical package or manifest is discarded.

The Pages build restores original URLs from [paths.json](paths.json), so existing
installation links and cached editor assets continue to work. Do not edit archived
file contents: their original bytes are retained.

`tools/package-editors.py` archives superseded releases automatically.
